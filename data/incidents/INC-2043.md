# INC-2043: Upstream API rate limit (HTTP 429) in payments_sync

- **Date:** 2026-09-16
- **Severity:** SEV-3
- **Pipeline:** payments_sync

## Summary

On 2026-09-16, the pull_payments_api task failed in the payments_sync pipeline. Failure type: Upstream API rate limit (HTTP 429). Payment reconciliation and the refunds dashboard showed stale data until the fix.

## Timeline (UTC)

- 02:51 Alert fired: pull_payments_api failed.

- 04:23 Root cause identified.
- 05:35 Fix applied and the failed task cleared.
- 06:16 Pipeline completed and dashboards refreshed.

## Root cause

The provider API allows a limited number of requests per minute, and the task (often together with a backfill or another DAG) exceeded it.

## Resolution

Wait for the rate window to reset, then clear the task. Put API-calling tasks in an Airflow pool with limited slots.

## Follow-ups

- Use a shared pool for each external API.
- Do not run backfills during the daily window.
