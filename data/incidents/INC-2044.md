# INC-2044: Expired cloud credentials mid-task in payments_sync

- **Date:** 2026-09-29
- **Severity:** SEV-2
- **Pipeline:** payments_sync
- **Failed task:** normalize_payments
- **Duration:** 126 minutes
- **Impact:** payment reconciliation and the refunds dashboard

## Summary

On 2026-09-29, the normalize_payments task failed in the payments_sync pipeline. Failure type: Expired cloud credentials mid-task. Payment reconciliation and the refunds dashboard showed stale data until the fix.

## Timeline (UTC)

- 02:42 Alert fired: normalize_payments failed.
- 02:52 On-call engineer acknowledged and opened the task log.
- 03:38 Root cause identified.
- 04:22 Fix applied and the failed task cleared.
- 04:48 Pipeline completed and dashboards refreshed.

## Root cause

The task ran longer than the one-hour limit of its assumed IAM role session, so the temporary credentials expired mid-task.

## Resolution

Clear the task to re-run with new credentials. Use a refreshable session so credentials renew automatically, or split the work into shorter tasks.

## Follow-ups

- Use auto-refreshing credentials in the shared io helpers.
- Alert when tasks approach 50 minutes.
