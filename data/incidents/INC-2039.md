# INC-2039: Expected source file is missing in orders_etl

- **Date:** 2026-09-02
- **Severity:** SEV-3
- **Pipeline:** orders_etl
- **Failed task:** extract_orders
- **Duration:** 114 minutes
- **Impact:** the daily sales dashboard and the finance revenue report

## Summary

On 2026-09-02, the extract_orders task failed in the orders_etl pipeline. Failure type: Expected source file is missing. The daily sales dashboard and the finance revenue report showed stale data until the fix.

## Timeline (UTC)

- 02:55 Alert fired: extract_orders failed.
- 03:05 On-call engineer acknowledged and opened the task log.
- 03:46 Root cause identified.
- 04:26 Fix applied and the failed task cleared.
- 04:49 Pipeline completed and dashboards refreshed.

## Root cause

The upstream export job had not written the day's partition (it finished late or failed), so the expected parquet file did not exist when the task ran.

## Resolution

If the export is late, wait for it to finish and the _SUCCESS marker to appear. Clear the failed task so it retries against the new files.

## Follow-ups

- Put a sensor on the _SUCCESS marker before extracting.
- Alert the export owners when their job misses its expected finish time.
