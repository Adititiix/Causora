# INC-2040: Null value in a NOT NULL column in orders_etl

- **Date:** 2026-09-07
- **Severity:** SEV-2
- **Pipeline:** orders_etl
- **Failed task:** load_orders_fact
- **Duration:** 203 minutes
- **Impact:** the daily sales dashboard and the finance revenue report

## Summary

On 2026-09-07, the load_orders_fact task failed in the orders_etl pipeline. Failure type: Null value in a NOT NULL column. The daily sales dashboard and the finance revenue report showed stale data until the fix.

## Timeline (UTC)

- 02:37 Alert fired: load_orders_fact failed.
- 02:47 On-call engineer acknowledged and opened the task log.
- 04:08 Root cause identified.
- 05:19 Fix applied and the failed task cleared.
- 06:00 Pipeline completed and dashboards refreshed.

## Root cause

Some source rows arrived with a null in a column the target table requires (for example guest checkouts without a customer_id), and the transform passed the nulls through.

## Resolution

Update the transform to default or filter nulls as the schema doc specifies. Clear the failed load.

## Follow-ups

- Validate required columns before loading.
- Review new product features with data owners.
