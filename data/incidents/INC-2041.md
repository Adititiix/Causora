# INC-2041: Column renamed upstream breaks a transform in orders_etl

- **Date:** 2026-09-09
- **Severity:** SEV-3
- **Pipeline:** orders_etl
- **Failed task:** transform_orders
- **Duration:** 198 minutes
- **Impact:** the daily sales dashboard and the finance revenue report

## Summary

On 2026-09-09, the transform_orders task failed in the orders_etl pipeline. Failure type: Column renamed upstream breaks a transform. The daily sales dashboard and the finance revenue report showed stale data until the fix.

## Timeline (UTC)

- 02:36 Alert fired: transform_orders failed.
- 02:46 On-call engineer acknowledged and opened the task log.
- 04:05 Root cause identified.
- 05:14 Fix applied and the failed task cleared.
- 05:54 Pipeline completed and dashboards refreshed.

## Root cause

The storefront team renamed the column customer_tier to loyalty_tier in orders_raw on 2026-08-28, but the transform code still reads customer_tier.

## Resolution

Update the transform to use the new column name, or add an alias mapping old to new. Clear the failed task in Airflow so it re-runs for the failed date and confirm downstream tasks succeed.

## Follow-ups

- Add a schema contract check at the start of the pipeline that fails fast and lists the missing columns.
- Subscribe pipeline owners to upstream schema-change announcements.
