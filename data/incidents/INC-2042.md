# INC-2042: Worker disk full in clickstream_ingest

- **Date:** 2026-09-12
- **Severity:** SEV-2
- **Pipeline:** clickstream_ingest
- **Failed task:** sessionize_events
- **Duration:** 84 minutes
- **Impact:** the web funnel dashboard and product analytics

## Summary

On 2026-09-12, the sessionize_events task failed in the clickstream_ingest pipeline. Failure type: Worker disk full. The web funnel dashboard and product analytics showed stale data until the fix.

## Timeline (UTC)

- 02:23 Alert fired: sessionize_events failed.

- 03:00 Root cause identified.

## Root cause

The worker's /tmp volume was full because intermediate files from earlier failed runs were never cleaned up.

## Resolution

Delete stale files in /tmp/airflow on that worker. Add cleanup in a finally block.

## Follow-ups

- Schedule a cleanup job for old temporary files.
- Alert when worker disk usage passes 80 percent.
