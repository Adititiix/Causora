# INC-2033: Source data freshness check failed in orders_etl

- **Date:** 2026-08-16
- **Severity:** SEV-3
- **Pipeline:** orders_etl
- **Failed task:** validate_orders
- **Duration:** 76 minutes
- **Impact:** the daily sales dashboard and the finance revenue report

## Summary

On 2026-08-16, the validate_orders task failed in the orders_etl pipeline. Failure type: Source data freshness check failed. The daily sales dashboard and the finance revenue report showed stale data until the fix.

## Timeline (UTC)

- 02:54 Alert fired: validate_orders failed.
- 03:04 On-call engineer acknowledged and opened the task log.
- 03:28 Root cause identified.
- 03:54 Fix applied and the failed task cleared.
- 04:10 Pipeline completed and dashboards refreshed.

## Root cause

The CDC replication connector that copies source changes into the raw table stalled, so no new rows arrived and the data became older than the freshness SLA.

## Resolution

Restart the CDC connector. Clear the failed check task.

## Follow-ups

- Alert on CDC connector lag.
- Run the freshness check earlier than the main DAG.
